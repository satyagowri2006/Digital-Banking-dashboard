# Digital Banking Dashboard

A full-stack MERN application for personal banking and financial management.

## Features
- Account Management
- Transaction History
- Budget Tracking
- Financial Goals
- Loan Management
- Real-time Notifications
- Analytics Dashboard

## Tech Stack
- MongoDB
- Express.js
- React.js
- Node.js

## Installation

1. Clone the repository
2. Run `npm run install-all` to install all dependencies
3. Configure environment variables in server/.env and client/.env
4. Run `npm run dev` to start both frontend and backend
